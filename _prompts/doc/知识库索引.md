# 知识库索引

---

## 受众说明

本索引挂在 **yt-boot 基础库仓库**。文档分两类：

| 类型 | 用途 | 在本仓何时使用 |
|------|------|----------------|
| **库维护** | 改 yt-boot 包、插件、配置段、封装边界 | 本仓日常开发 / `check_code` |
| **业务消费者** | 约束基于 yt-boot 的业务工程（BFF/领域/前端） | 本仓**不**生成业务代码；规范供业务仓遵循或拷贝 |

接入方式见仓库根目录 [Boot脚手架接入教程.md](../../Boot脚手架接入教程.md)。

### 统一术语（脚手架视角）

| 术语 | 含义 | 禁止写法 |
| ---- | ---- | -------- |
| 入口编排服务（BFF） | 对外 API、鉴权、跨域读聚合/写 Saga 的可部署单元 | 把具体产品名（如某 `*-bff`）写成适用范围 |
| 领域服务 | 单一业务边界内的读写与本地事务 | 把具体域名写成脚手架强制清单 |
| 领域 client | 业务工程独立 HTTP 契约模块，路径惯例 `{client}/{domain}`；**非** yt-boot 内模块 | `yt-client` 等产品模块名当作 boot 能力 |
| `router_prefix` | 入口编排对外前缀，按端在配置中设置 | 把某一端前缀写成全站唯一强制值 |
| Encoder / `MustRegister` | HTTP 业务出口编码适配；须显式注册 | 把预制 Encoder JSON 写成全站强制契约 |
| `{unit}` / `{resource}` | 可部署单元 / 资源路径占位 | 在「适用范围」写死具体业务资源名 |
