# 基础库能力索引

---

## 文档说明

本文档是 **gitee.com/hq_project/yomi-boot 基础库能力总览索引**：列出各能力库的简要职责与仓库落位，供 Agent / Skill 在设计、实现、巡检前快速判断「是否已有可复用能力」。

| 项 | 说明 |
| -- | ---- |
| 模块名 | `gitee.com/hq_project/yomi-boot`（本仓库根） |
| Import 前缀 | `gitee.com/hq_project/yomi-boot/{包}`，如 `gitee.com/hq_project/yomi-boot/bootstrap` |
| 能力启用 | 多数经 YAML 配置段 `enabled`（及同类开关）按需裁剪；细则见 [Go配置规范](./knowledge/go/Go配置规范.md) |
| 架构细则权威 | [Go架构规范](./knowledge/go/Go架构规范.md) §3.3 |
| 强制使用规则 | [_prompts/rules/基础库优先使用规则.md`](../rules/基础库优先使用规则.md) |

**使用方式**：先读本索引匹配能力 → 有候选则阅读对应包源码 → 能满足需求则**必须**使用该库；无候选或需新增时，**必须先**按《基础库优先使用规则》§2.5 在 A/B/C 中明确选择新增方式后再实现。

## 1. 生命周期与装配

| 库 | 能力简述 | 位置 |
| -- | -------- | ---- |
| `bootstrap` | 基础设施初始化与 HTTP 服务装配：`MustInitInfra`、`MustBuildServer`、默认中间件链、内置插件编排、`InfraOptions` 扩展 | `bootstrap/` |
| `plugin` | 插件生命周期框架：`Plugin` / `Host` / `Runtime` / 状态机 | `plugin/` |
| `{lib}/plugin` | 各能力库内置生命周期插件（如 `db/plugin`、`redis/plugin`）；包名 `{lib}plugin` | `{lib}/plugin/` |
| `config` | 配置加载：Section/Registry/Document、严格根 key、环境变量展开；`MustLoad` / `MustLoadDocument` Fail Fast | `config/` |
| `runner` | 进程启动/关闭生命周期（`Run` / `RunServer`） | `runner/` |
| `appctx` | 应用元数据上下文（名称、环境、版本） | `appctx/` |
| `banner` | 启动横幅打印 | `banner/` |

## 2. HTTP / 路由 / 协议适配

| 库 | 能力简述 | 位置 |
| -- | -------- | ---- |
| `router` | Gin 路由与 `Registrar` 注册接口 | `router/` |
| `handler` | HTTP 协议适配：`BindAndHandle`、健康检查等 | `handler/` |
| `response` | HTTP 出口 `Encoder` 接口与显式 `MustRegister` | `response/` |
| `cors` | CORS 跨域中间件 | `cors/` |
| `requestguard` | 请求体大小限制 + 请求级超时中间件 | `requestguard/` |
| `traceid` | `X-Trace-ID` Header 入站生成/读取与出站传播 | `traceid/` |
| `httprecord` | HTTP 访问记录中间件、Kafka 发布；提供消费端点骨架（不含业务消费逻辑） | `httprecord/` |
| `logger` | Zap 日志初始化、文件轮转、访问日志中间件 | `logger/` |

## 3. 数据访问与事务

| 库 | 能力简述 | 位置 |
| -- | -------- | ---- |
| `db` | GORM 打开、`TxExecutor`、`BaseRepository`、`BaseModel`、SQL 安全约定 | `db/` |
| `idempotency` | 业务幂等：`sys_biz`、`Guard` / `Execute`；Redis + 锁 + DB 三层 | `idempotency/`（含 `sys_biz.sql`） |
| `dtm` | DTM Saga 客户端、GORM barrier、`TxRunner`、Action/Compensate 绑定 | `dtm/`（含 `barrier.sql`） |
| `event` | 可选 Outbox/Inbox 事件发布/消费组件 | `event/`（含 `sql/sys_event.sql`） |

---

## 4. 缓存、锁、限流与调度

| 库 | 能力简述 | 位置 |
| -- | -------- | ---- |
| `redis` | `RedisService` / `RedisHelper`；含滑动窗口限流等 Lua 原语 | `redis/` |
| `distlock` | 基于 Redsync 的分布式锁与看门狗 | `distlock/` |
| `ratelimit` | 调用式限流门面 `Allow` / `AllowN`（依赖 Redis，不进默认中间件链） | `ratelimit/` |
| `roundrobin` | 分布式定时轮询调度（如 event outbox 内部使用） | `roundrobin/` |
| `cronjob` | 业务日历定时任务（cron + distlock 互斥）；禁止业务直引 `robfig/cron` | `cronjob/` |
| `worker` | 后台 worker 池（channel / ants） | `worker/` |
| `snowflake` | 雪花 ID 生成器 | `snowflake/` |

---

## 5. 服务发现、RPC 与消息

| 库 | 能力简述 | 位置 |
| -- | -------- | ---- |
| `consul` | 服务注册/注销/发现、HTTP URL 解析与负载均衡 | `consul/` |
| `rpc` | HTTP RPC 读客户端（Consul + 重试 + 熔断）；跨域写走 DTM | `rpc/` |
| `kafka` | Kafka 生产者/消费者（segmentio/kafka-go）及测试封装 | `kafka/` |
| `redisstream` | Redis Stream 发布/消费组；复用 `RedisClient`，不耦合 `RedisService`；按需启用 | `redisstream/` |
| `event` | Outbox/Inbox 可靠领域事件（当前传输侧接 Kafka）；按需启用 | `event/` |
| `ws` | 独立端口 WebSocket（底层 coder/websocket）：Config 配 Processor/可选 Handler；ConnID 仅服务端；心跳/寿命/`MaxConnections`；无 yml 段；小文件可走 WS，大文件走 `filestorage` | `ws/` |

## 10. 场景速查（按需匹配）

| 你需要… | 优先看 |
| -------- | ------ |
| 进程启动、插件装配、中间件链 | `bootstrap`、`plugin`、`config`、`runner` |
| HTTP 绑定/响应/路由 | `handler`、`response`、`router` |
| DB / 本地事务 / Repository 基类 | `db` |
| 业务幂等 | `idempotency` |
| 跨域 Saga | `dtm` |
| Redis / 分布式锁 / 调用式限流 | `redis`、`distlock`、`ratelimit` |
| 定时任务 | `cronjob`（内部轮询用 `roundrobin`） |
| 服务发现与读 RPC | `consul`、`rpc` |
| 异步消息 | 按需选用 `kafka` 或 `redisstream`；可靠领域事件另看 `event` |
| WebSocket 长连接 | `ws`（独立端口 Server/Client；ConnID 仅服务端）；小文件可走 WS，大文件走 `filestorage`，WS 只做信令 |
| 鉴权令牌 | `token` |
| 加解密 / 哈希 / 密码 | `bc/*` |
| 对象存储 | `filestorage`（大文件上传/下载；勿用 `ws` 整包） |
| 雪花 ID | `snowflake` |
| 错误码 / 信封 DTO | `errors`、`shared/error`、`shared/dto` |
| 集成测试 HTTP 调用 | `testclient` |

## 11. 维护约定

- 新增或下线能力包时：**同步更新本索引**，并核对 [Go架构规范](./knowledge/go/Go架构规范.md) §3.3。
- 本索引只做能力与落位速查；配置段、启用开关、装配顺序等细则以知识库权威文档为准。
- gitee.com/hq_project/yomi-boot **不包含**业务 handler/usecase/domain 与各领域 `bizerr`；业务逻辑落在业务仓。
