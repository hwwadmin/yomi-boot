# 知识库加载规则

---

## 1. 加载流程

```
读取知识库索引 ──▶ 解析文档列表 ──▶ 按需加载目标文档
```

## 2. 索引文档

知识库索引文档位于：`_prompts/doc/知识库索引.md`

该索引包含以下信息：
- 名称：文档标题
- 描述：文档内容摘要
- 目录地址：文档实际路径

## 3. 加载规则

### 3.1 读取索引

首先读取 `_prompts/doc/知识库索引.md` 获取可用文档列表。

### 3.2 禁止绕过

禁止绕过知识库索引直接加载文档。所有文档必须通过索引进行加载。

### 3.3 按需加载

根据任务需求，从索引中选择对应的文档路径进行加载。

### 3.4 文档归类

- 架构说明、技术选型、模块边界、编码规范、设计基线、行为原则等**静态知识**，统一登记到知识库索引。
- 规范类文档即使曾以 Skill 形态存在，一旦不再承载任务执行流程，也应迁入知识库，不再通过 Skill 列表加载。
- 知识库文档可以被 Skill、Agent、spec 引用，但引用时应优先指向知识库路径，而不是历史 Skill 路径。
